# Reasonally for desktop

Installers and updates for [Reasonally for desktop](https://reasonally.ai/download): Reasonally's
coding agent on macOS, Windows and Linux.

**Download:** https://reasonally.ai/download

This repository only hosts releases: the installers, their checksums (`SHA256SUMS.txt`) and the
files the app reads to update itself. The app's source code isn't here.

Questions or problems: support@reasonally.ai
